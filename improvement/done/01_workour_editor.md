# Workout Editor

As a user, I want to be able to create my workout right from the app as another option to add workout in the app.
I can either select the import a file, or create a workout that open a new page for the workout editor.

The workout is agnostic from watt, it is always based on the FTP% 

In the workout editor I am able to drag and drop building block:
- steady pace
- warmup
- cool down
- interval


As a user I am able to edit the property of the building block:
- editing the duration
- editing the power: one value for steady pace, two value for warm up/cooldown
- for interval I am able to edit btoh the number of interval, the duration and power of the intensity, and the duration and power of the recovery

As a user I am able to delete/move block to re-organize the workouts

As a user, I can see at the top the total duration of the workout


As a user I can save the file created and it will appear in the main screen:w
